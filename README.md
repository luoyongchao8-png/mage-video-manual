# 马哥赢创 · 爆款短视频方法论

两册交互式学习手册，静态站点，手机 / 桌面通用。

- 第一册 `book1.html` — 爆款短视频结构方法论（开头 / 中间 / 结尾 / 引流涨粉）
- 第二册 `book2.html` — AIGC 视觉奇观开头实操手册（首帧图 / 提示词 / 奇观配方）
- `index.html` — 门户首页

## 本地预览

```bash
python -m http.server 8000
# 打开 http://127.0.0.1:8000
```

## 更新线上内容

改完文件后提交并推送，GitHub Pages 会自动重新部署（约 1 分钟）：

```bash
git add -A
git commit -m "更新手册内容"
git push
```

## 说明

- 站内路径全部使用相对路径，因此部署在子目录下也能正常工作
- `.nojekyll` 用于关闭 Jekyll 处理，避免下划线开头的目录被忽略
- 阅读清单进度保存在各自浏览器的 localStorage，不会上传到服务器
